# Asset Quality Checklist

Apply to every generated or sourced asset before status becomes `approved`.

## Visual

- [ ] Living Field Journal gouache/ink treatment matches approved references.
- [ ] Upper-right key light, ink weight, palette, and detail density match.
- [ ] Silhouette reads at intended display size.
- [ ] No text, numbers, letters, watermark, logo, duplicate object, unwanted character, or major artifact.
- [ ] No important element is cropped; UI safe zones stay clear.
- [ ] Pathfinder costume, proportions, handedness, age tone, and equipment match reference.

## Educational

- [ ] Cos reads horizontal/x through shape and motion cue.
- [ ] Sin reads vertical/y through shape and motion cue.
- [ ] Tan reads as a relation between two signs, not an independent coordinate.
- [ ] All reads as combined signs and never as an ordinary shortcut.
- [ ] Pathfinder is the only main character.
- [ ] Quadrant meaning uses direction/position/icon plus color.
- [ ] All math and labels remain digital HTML/SVG.

## Technical

- [ ] Path, lowercase kebab-case filename, dimensions, format, alpha, and manifest entry match.
- [ ] Transparent edges are clean at 100% and against light/dark test surfaces.
- [ ] Web-ready file is optimized and initial essential art stays within 2 MB budget.
- [ ] Asset remains readable at 768 px viewport height and tablet crop.
- [ ] Static fallback exists for motion-dependent states.

## Accessibility

- [ ] Planned alt text states purpose, not decoration.
- [ ] Digital text/controls meet WCAG 2.2 AA.
- [ ] Pattern, icon, label, or position duplicates every color cue.
- [ ] Effect does not lower text contrast or require motion perception.
- [ ] Decorative asset can be hidden from assistive technology.
